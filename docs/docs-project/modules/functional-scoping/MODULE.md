# Module — Cadrage fonctionnel

## Objectif

Accompagner l’utilisateur de l’idée ou des nouveaux besoins jusqu’à un cadrage fonctionnel explicitement validé pour une version précise.

## Périmètre

V1 couvre l’entretien avec l’IA à partir de textes, l’arbitrage des propositions, la structuration du catalogue en modules et fonctionnalités, les critères d’acceptation et les modifications manuelles. Trois validations se succèdent : synthèse, catalogue et cadrage final.

Une règle indispensable non clarifiée bloque la validation finale ; l’utilisateur peut la préciser ou reporter la fonctionnalité. Les questions non bloquantes peuvent rester visibles. L’absence de réponse ne vaut jamais approbation.

Les parcours et écrans, l’architecture, les choix techniques et les tâches de réalisation appartiennent à des phases ultérieures.

Le cadrage est rattaché à une [version de projet](../version-management/prepare-project-versions.md). Il est [sauvegardé et reprenable](../continuity/save-and-resume-scoping.md), avec un [historique consultable](../continuity/view-functional-history.md).

Aucune question fonctionnelle bloquante consignée. Les adaptations techniques des workflows existants et le fournisseur IA restent à étudier. Sources : description initiale et D02, D06, D07, D10 à D14 de la [synthèse V1](../../versions/v1/SCOPING-SUMMARY.md).
